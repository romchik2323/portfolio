# Telco Customer Churn Prediction Project

**Python • Machine Learning • PostgreSQL**

Анализ оттока клиентов телеком-компании с применением машинного обучения и SQL-аналитики.

## 📋 О проекте

Этот проект использует данные о клиентах телеком-компании для:

-  Прогнозирования оттока клиентов с помощью Machine Learning
-  Выявления ключевых факторов риска churn
-  SQL-анализа клиентской базы и поведенческих паттернов
-  Построения системы раннего предупреждения об оттоке

##  Стратегические рекомендации

### 🎯 Приоритетные действия

1. **Фокус на клиентах высокого риска**
   - Помесячные контракты + оптоволокно
   - Предлагать переход на долгосрочные контракты
   - Улучшать качество техподдержки

2. **Оптимизация тарифов**
   - Пересмотреть цены на оптоволоконные тарифы
   - Ввести скидки за долгосрочные контракты

3. **Улучшение сервиса**
   - Бесплатная техподдержка для новых клиентов
   - Программы лояльности для долгосрочных клиентов

4. **Мониторинг**
   - Регулярно отслеживать клиентов по модели риска
   - Быстро реагировать на признаки ухода

##  Методология

### 📊 Feature Engineering

- ** Демография**: пол, возраст, наличие партнера/иждивенцев
- ** Услуги**: телефон, интернет, дополнительные сервисы
- ** Контракты**: тип контракта, способ оплаты
- ** Финансы**: ежемесячные и общие платежи
- ** Лояльность**: tenure (время пользования услугами)

### 🗄️ SQL-аналитика

- Анализ распределения оттока по сегментам
- Выявление паттернов поведения перед уходом
- Расчет ключевых метрик удержания клиентов
