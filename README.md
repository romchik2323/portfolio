# Telco Customer Churn Prediction Project

Python Machine Learning PostgreSQL

Анализ оттока клиентов телеком-компании с применением машинного обучения и SQL-аналитики.

## 📋 О проекте

Этот проект использует данные о клиентах телеком-компании для:

- Прогнозирования оттока клиентов с помощью Machine Learning
- Выявления ключевых факторов риска churn
- SQL-анализа клиентской базы и поведенческих паттернов
- Построения системы раннего предупреждения об оттоке

## 🎯 Ключевые результаты

### 🔬 Основные находки:

- **26.5%** клиентов склонны к оттоку (Churn = Yes)
- Клиенты с **Month-to-month** контрактом в **3.2 раза** чаще уходят
- **Электронные чеки** ассоциируются с повышенным риском оттока
- **Fiber optic** интернет показывает наибольший churn rate

### 📊 Модель машинного обучения:

- **Алгоритм**: Random Forest Classifier  
- **Точность**: 85%
- **ROC-AUC**: 0.91 - отличная предсказательная способность
- **Recall**: 78% для класса "склонность к оттоку"
- **Precision**: 65% для класса "склонность к оттоку"

## 📊 Методология

### 1. Предобработка данных

- Очистка от пропущенных значений
- Преобразование категориальных переменных
- Обработка аномальных значений TotalCharges
- Масштабирование числовых признаков

### 2. Feature Engineering

Созданы ключевые признаки:

- **Демография**: пол, возраст, наличие партнера/иждивенцев
- **Услуги**: телефон, интернет, дополнительные сервисы
- **Контрактные условия**: тип контракта, способ оплаты
- **Финансы**: ежемесячные и общие платежи
- **Лояльность**: tenure (время пользования услугами)

### 3. SQL-аналитика

- Анализ распределения оттока по сегментам
- Выявление паттернов поведения перед уходом
- Расчет ключевых метрик удержания клиентов

### 4. Моделирование

- Random Forest для классификации
- Стратифицированное разделение на train/test (70/30)
- Балансировка классов через SMOTE
- Оптимизация гиперпараметров

## 📈 Ключевые переменные

### Целевая переменная
**Churn** - бинарный показатель оттока клиента

### Топ-5 наиболее важных признаков:
1. **Tenure** - длительность пользования услугами
2. **MonthlyCharges** - ежемесячные платежи
3. **Contract_type** - тип контракта
4. **InternetService** - тип интернет-услуги
5. **PaymentMethod** - способ оплаты

## 🔍 Бизнес-инсайты

### Подтвержденные гипотезы:

- **"Дорогие" клиенты не всегда лояльны** - высокие MonthlyCharges могут увеличивать риск оттока
- **Краткосрочные контракты рискованны** - month-to-month клиенты наиболее нестабильны
- **Техническая поддержка снижает отток** - клиенты с TechSupport реже уходят
- **Электронная биллинг увеличивает риск** - возможно из-за меньшего контакта с клиентом

### Практическое применение:

- Система скоринга клиентов по риску оттока
- Приоритизация retention-кампаний
- Оптимизация тарифной политики
- Улучшение сервисного обслуживания
